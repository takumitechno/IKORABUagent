# 読者像（内部用・画面には出さない）

表向きの位置づけ: **「はじめての転職・未経験転職で迷っている20代のためのメディア」**。
画面・記事で読者を年収や属性でラベリングしない（「年収350万円以下向け」等は書かない）。

## 主要ペルソナ

- 20代中心（第二新卒〜20代後半）
- 現年収はおおむね250〜350万円程度を想定（**内部の想定。画面には出さない**）
- 正社員経験が少ない / ない。フリーター・派遣・アルバイト経験がある
- 接客・販売・サービス系から別の職種を検討している
- 初めての転職、未経験職種への転職
- 自分の経歴に自信がない、何が向いているか分からない
- 年収は大きく下げたくない。土日休みなど働き方も改善したい
- IT / 事務 / 営業などに興味はあるが、実態が分からない

## 読者の悩み（記事・見出しに使う言葉の素材）

| 読者の気持ち | 見出しにするなら |
|---|---|
| 転職したいけど何をすればいいか分からない | 何から始める？ |
| 自分の経歴でどんな職種に行けるか分からない | 自分にできる仕事って？ |
| 正社員経験が少なくて不安 / 未経験の仕事へ行けるのか | 未経験でも大丈夫？ |
| 給料が低い / 待遇を改善したい | 給料は下がる？上げられる？ |
| 今の働き方を続けるのが不安 | 土日休みにできる？ |
| 接客しかしていない | 接客しかしてないけど転職できる？ |
| PCが苦手 | PCが得意じゃなくても事務に行ける？ |
| 履歴書・職務経歴書・面接に自信がない | 面接って何を準備する？ |
| 仕事を続けられるか自信がない / 転職回数が気になる | 転職回数、多いと不利？ |
| 希望に近い仕事があるか相談したい | 誰に、何を相談すればいい？ |

## 言葉づかい

- 使わない（多用しない）: 市場価値 / キャリア戦略 / 人的資本 / ポータブルスキル などの業界用語
- 使う: 読者が自分で言いそうな言葉（「接客しかしてない」「PCが苦手」「土日休みにしたい」）
- 不安をあおらない。成果を保証しない（「必ず」「確実に」）
- 「会社によって違う」ことは断定せず、確かめ方を書く
