# 商談で確認したいこと（PARTNER_DISCOVERY_QUESTIONS）

商談用・非公開。答えをこちらで推測して埋めない。聞いた内容は、正式提携の判断・Pilot の範囲・計測の設計に使う。

## 必ず聞く TOP10

1. **支援できる人**: 年齢・地域・経歴（正社員経験の有無、フリーター・派遣・アルバイト中心の人）のどこまでが対象か
2. **紹介しやすい職種・求人が厚い職種／紹介しにくい層**: 記事・投稿のテーマ選びの前提になる
3. **面談のキャパシティと初回連絡の目安**: 1か月に受けられる面談数、申し込みから初回連絡までの時間
4. **今の流れ**: 登録 → 予約 → 面談 → 内定 → 入社のそれぞれで、どこが課題か（数値は出せる範囲で）
5. **Instagram で達成したいこと**: 認知・登録・採用広報・ブランドなど、何を一番に置くか
6. **既存 TikTok で反応のよいテーマ**: 企画の材料として共有してもらえるか（素材の媒体横断利用の可否も）
7. **成果条件**: 「承認面談」の定義、否認条件（重複・既登録・対象外・No Show）、判定までの期間
8. **成果データの返し方**: 登録・予約・面談・承認・否認を、どの粒度・頻度で返せるか（CSV でよいか、partner ID・UTM の扱い）
9. **ブランド・素材の利用**: 社名・ロゴ・実績・求人情報・写真・出演者を、メディアと SNS でどこまで使えるか
10. **承認フロー・法務・終了時**: 投稿と記事の確認者と日数、法務・個人情報の確認窓口、契約終了時の引き渡し

## すべての確認項目

### 対象者とサービス
- 支援対象の年齢・地域・経歴、正社員経験の有無、フリーター／派遣／アルバイトの扱い
- 得意な職種・求人が厚い職種・紹介しにくい層
- 面談キャパ、初回連絡の SLA、オンライン面談の可否
- 相談の流れ（申し込み → 連絡 → 面談 → 紹介）と、無料表記などの表記ルール

### 現状の集客
- 今の集客チャネル（既存サイト・TikTok・広告・紹介など）
- TikTok で反応の良いテーマ・形式、投稿頻度、制作体制
- Instagram の現状（アカウントの有無、目的、投稿頻度、運用担当）
- 現在の CPA / CPL / 面談獲得単価（出せる範囲で。推測はしない）

### 成果と計測
- 成果条件、否認条件、重複・既登録の判定期間、No Show の扱い、判定期限
- 成果データの返却（項目・頻度・形式・担当）、partner ID、UTM の命名
- 帰属の考え方（最初の接点／最後の接点／アシスト）を、正式提携後に決めること

### ブランド・素材・権利
- ブランド名・ロゴの使用範囲、実績・求人の掲載可否
- 素材（TikTok 動画・写真）の利用許諾、出演者の同意、音源
- 投稿・公開の承認フロー、承認者、修正の回数

### 法務・個人情報・終了時
- 法務の確認窓口、個人情報の扱い（匠側では氏名・連絡先を持たない前提）
- 広告・PR 表記の方針
- 契約終了時の引き渡し範囲（記事・データ・ドメイン）

### ドメイン・ホスティング
- 既存ドメイン内に置けるか（CMS・権限・社内の運用）、サブドメイン、独立ドメインのどれが現実的か
- 詳しくは [DOMAIN_HOSTING_OPTIONS.md](DOMAIN_HOSTING_OPTIONS.md)
