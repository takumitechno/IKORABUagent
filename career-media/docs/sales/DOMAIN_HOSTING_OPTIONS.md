# ドメイン・ホスティングの方針（商談で確認）

商談用・非公開。2026-10-11時点の依頼者指定は **新規ドメイン**。既存ドメインの検索評価や流入を引き継ぐ計画にはしない。今回はドメイン取得・DNS変更・公開をしていない。

## 商談で決めること

- 先方所有を前提に、登録名義・管理権限・取得更新費用・契約終了時の管理者を決める。
- メディア名と既存公式サイトとの関係、公式サイトからの案内の可否を確認する。
- 公開・保守・バックアップ・費用負担の担当を決める。ドメイン・サーバー実費は月額制作費に含まない。
- 新規ドメインのSEO成果は3か月で保証しない。SNS流入と各段階の反応を先に観測する。

## 配置方法

| 形式 | 引き継ぐもの | 注意点 |
| --- | --- | --- |
| Next.jsで運用 | ソース・記事・設定・起動手順 | 実行環境と保守担当が必要 |
| 静的サイトとして配置 | export/site（HTML・JS・CSS・フォント） | 記事・条件整理は利用可。記事検索のサーバー絞り込みは含まない |
| 別CMSへ記事を移管 | Markdown・メタデータ・URL一覧 | 移管作業は別途範囲を合意 |

書き出しは中立版・noindex・本番送客OFF。正式公開の表記・相談条件・本番送客・検索公開は、人による承認後に判断する。所有と終了は [OWNERSHIP_AND_EXIT.md](OWNERSHIP_AND_EXIT.md) を参照。
