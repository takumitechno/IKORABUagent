# 法務・個人情報で、あとで専門家・所管に確認すること

商談用・非公開。**ここでは法的な判断をしていない。** 「許可が不要」とも「該当しない」とも断定しない。
弁護士・社会保険労務士・所管（厚生労働省・都道府県労働局など）に確認する事項の一覧。

## 初期 MVP の原則（今回の作り）

- 匠側では、氏名・電話番号・メール・履歴書などの個人情報を持たない
- 条件整理チェックの回答は、ブラウザの中（sessionStorage）だけに置き、どこにも送らない
- 相談したい人は、本人が提携先の申込ページへ進む（今回のデモでは移動しない）
- 計測は匿名のセッション ID と、ページ・ボタン単位の記録だけ（本番の解析ツールは未接続）
- 正式な連携（成果データの返却など）は、別の設計と契約で行う

## 確認したい事項

| 論点 | 確認したいこと |
| --- | --- |
| 匠の行為の位置づけ | メディア運営・広告・募集情報等提供・職業紹介のどれに当たるか。送客の形や成果報酬の条件で変わるか |
| 特定募集情報等提供事業 | 求職者の情報を匠側で集める場合に届出が必要になるか（今回は集めない） |
| 成果報酬の条件 | 面談単位の成果報酬が、職業安定法上の問題を生まない形か（手数料規制との関係） |
| 第三者提供 | 提携先から成果ステータスを受け取るときの根拠・同意・記録 |
| 仮名化 ID | session_id と提携先の管理 ID を突き合わせる場合の扱い |
| Cookie・解析ツール | 本番で解析ツールを入れる場合の通知・同意（電気通信事業法の外部送信規律を含む） |
| 外部送信 | 計測タグ・埋め込みの送信先の公表方法 |
| 広告・PR 表記 | 相談の案内がステルスマーケティング規制（景品表示法）上の「広告」に当たるかと、表示の方法 |
| 提携先の許可情報 | 有料職業紹介事業の許可番号・表記の確認（一次情報で確認してから掲載） |
| 個人データの保存・削除 | 成果データの保管期間、削除の手順、委託・再委託の範囲 |
| 契約終了時 | アクセス権の撤回、データの返却・削除、記事の著作権と利用権 |
| 無料表記 | 「相談は無料」の表記の根拠（職業安定法の手数料規制）と、提携先の表記ルール |
| 求人情報の扱い | 求人を記事に載せる場合の明示事項・正確性の責任 |

## 今回あえてしていないこと

- 個人情報を受け取るフォーム・バックエンド
- 本番の解析ツール・広告ピクセル・CRM・提携先 API との接続
- 本番公開（noindex はアクセス制限ではないため、公開しないことで非公開を保っている）
