### キャプション

「接客しかしてないから、アピールできることがない」と感じたら。
接客の仕事は、分けてみると、ほかの仕事でも通じる経験がたくさん入っています。

・注文や要望を聞く → 聞き取って確認する
・混雑時の対応 → 優先順位をつけて同時に進める
・クレーム対応 → できること・できないことを伝える
・新人への説明 → 手順を言葉にして教える
・売上の目標 → 数字を意識して工夫する
・レジ締め・在庫確認 → 数字を正確に扱う

書類では「状況 → したこと → 結果」の順に。数字は覚えている正確なものだけで大丈夫です。
事務・営業など、応募先に合わせてどう伝える？ 職種ごとのつながりと職務経歴書の例文は、プロフィールのリンクから記事へ。
