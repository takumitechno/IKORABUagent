# UI更新 — 2026-10-10

読者像を「20〜30代・SNSをよく見る・最初は絵と短いコピーで選ぶ」に更新した。画面上で属性を低く扱う表現は使わない。

## 今回の変更

- Homeを12セクションから4つへ。ヒーロー、3つの読者経路、代表記事と検索、相談への入口に整理。
- 入口は「接客からデスクワーク」「給料と休み」「バイトから正社員」。既存SVGと色面を使い、全3経路をスマホでも表示する。
- トップの重複した相談説明・職種表・求人票図・手順・新着一覧を外す。詳しい内容は既存ページで読める。
- CTAは「希望を整理する」「まずは相談したい」。検索は記事の近くへ移動。
- スマホではカテゴリ帯と長いロゴ補足を省き、メニューから移動する。狭いプレビューの横はみ出しを解消。
