# ガイドB: 給料と休みを比べる

## 目的
給料と休みを「同じものさしで比べる」ガイドであることを伝える。お金をもうける話に見せない。

## 使用場所
トップの「よくある3つのケース」B のカード上部（16:9）。採用したときだけ表示。

## 想定読者
今の給料は下げたくないが、土日休みや年間休日も増やしたい20代。

## 避けたい表現
- お札・金貨の山、¥マークの強調
- 数字・曜日・グラフの文字
- 悩んで頭を抱える姿

## 色味
ミントとオフホワイトが中心。コインは控えめな淡い黄、カレンダーの休日はティール。

## 構図
横長。中央に大きめの天びん。左の皿に小さなコインの束、右の皿に休日に印がついた無地のカレンダー。横に人物（小さめ）が手帳を持って見比べている。要素は少なく。

## 画像内テキスト
入れない（カレンダーは升目と印だけ）
