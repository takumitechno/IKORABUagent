# ガイドC: フリーター・正社員経験が少ない

## 目的
アルバイトの経験を否定せず、その経験を持って次へ進むことを伝える。

## 使用場所
トップの「よくある3つのケース」C のカード上部（16:9）。採用したときだけ表示。

## 想定読者
フリーターや正社員経験が少なく、何から始めればいいか迷っている20代。

## 避けたい表現
- アルバイトを恥ずかしいもの・暗いものとして描く
- 合格・内定を連想させる花束や賞状
- 顔のアップ、書類の細かい文字

## 色味
オフホワイト中心。エプロンはサンド、書類とペンはティール、小さくオレンジ。

## 構図
横長。机に向かって座る人物（横向き、小さめ）。机の上にはたたんだエプロンと、線だけで書かれた書類、ペン。窓から明るい光。要素は少なく。

## 画像内テキスト
入れない（書類の行は線）

## 参考にするサイト内トーン
`motifs.ts` の idcard と list、トップのヒーロー。
