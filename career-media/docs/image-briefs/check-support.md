# 条件整理チェックの補助イラスト

## 目的
「診断」や「テスト」ではなく、自分の条件をノートに整理する道具だと感じてもらう。説明文があるので画像は飾り。

## 使用場所
トップの「条件整理チェック」セクション左（スマホ高さ96px、デスクトップ高さ160px）。今の SVG（`CheckIllustration`）の置き換え候補。小さく表示されるので、細部より形の分かりやすさを優先。

## 想定読者
3分で終わるなら試してみようか、と思っている人。

## 避けたい表現
- 点数・グラフ・合否のマーク（判定ツールに見える）
- ノートパソコンの画面に文字や UI が描かれたもの
- 人物の手元のアップ（指が崩れやすい）

## 色味
透過背景。ノートはオフホワイト、チェックとペンはティール、付箋にオレンジを少し。

## 構図
正方形の中央に、開いたノートかクリップボード1つ、チェック印3つ（文字の代わりに短い線）、ペン1本、小さな付箋1枚。周りは透明で余白多め。

## 画像内テキスト
入れない（行は線で表す）

## 参考にするサイト内トーン
今のチェックリストのモチーフ（`motifs.ts` の checklist）。それを少しだけ立体感のある紙の質感にした程度。

## Prompt

A slim teal pen rests beside it and one small orange sticky note peeks from the top edge. Clean, friendly, minimal, with generous empty space around the object on a fully transparent background. The shapes must stay readable when shown at about 100 pixels tall.
