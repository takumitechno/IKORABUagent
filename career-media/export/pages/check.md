条件整理チェック

# 希望と経験を整理して、相談に備える。

13問で希望や経験を整理し、相談用のメモを作れます。適職の判定はしません。

- 約3分
- 登録不要
- 回答の送信なし

**メモの見本を見る**

回答後のメモは、コピー・印刷して相談に持っていけます。

相談用メモの見本 架空の例

- **譲れない条件**
  土日休み。今の収入も大切にしたい。
- **活かせる経験**
  接客でお客様の希望を聞き、商品を案内した。
- **相談で聞きたいこと**
  未経験から応募できる事務職は？

回答に合わせて、比較する候補や求人で確認する項目も整理します。適職・内定の判定はしません。

1. 状況
2. 経験
3. 条件
4. スタイル
5. 結果

## いまの状況

まずは現在の状況と、転職を考えている時期を教えてください。

現在の働き方に近いものはどれですか？

( ) 正社員として働いている

( ) 契約社員・派遣社員として働いている

( ) アルバイト・パートで働いている

( ) 今は働いていない

( ) 答えたくない・どれにも当てはまらない

いつごろまでに働き始めたいですか？

( ) できるだけ早く（1か月以内）

( ) 3か月以内

( ) 半年以内

( ) まだ決めていない・情報収集中
