# 運営者情報

はじめて転職ガイドは、未経験からの転職を考える方が、仕事や働き方について調べ、自分の希望を整理し、必要なときに相談先を見つけられるようにするための情報メディアです。

**このサイトは提案用のデモです（非公開）。**下の運営者・相談先の情報は、正式に公開するときに確定した内容を掲載します。

## メディア

| メディア名 | はじめて転職ガイド |
| --- | --- |
| 運営 | 提案用デモ（運営者は正式公開時に掲載） |
| 企画・制作 | 匠Technologies（企画・制作） |
| 所在地 | 確認中（正式公開前に確定予定） |
| お問い合わせ | 確認中（正式公開前に確定予定） |

## キャリア相談の相談先

記事や条件整理チェックの中でご案内するキャリア相談は、次の人材紹介会社が担当します。このメディア自体は、求人の紹介や職業紹介を行いません。

| 相談先 | 提携する人材紹介会社（正式公開時に掲載） |
| --- | --- |
| 事業 | 人材紹介（有料職業紹介事業） |
| 有料職業紹介事業許可番号 | 正式公開時に掲載 |

職業紹介事業の許可は、厚生労働省の[人材サービス総合サイト](https://jinzai.hellowork.mhlw.go.jp/JinzaiWeb/GICB101010.do?action=transition&screenId=GICB101010&params=1)で許可番号から確認できます。

## このメディアについて

未経験からの転職では、「何から調べればいいか分からない」「自分の経験をどう伝えればいいか分からない」といった迷いが生まれやすいものです。このメディアは、相談の手前の段階で、仕事や条件について自分のペースで調べ、整理できる場所として作っています。相談しなくても、記事と条件整理チェックだけで判断の材料が手に入ることを目指しています。

記事ははじめて転職ガイド編集部が企画・編集し、出典と情報確認日を明記しています。編集の考え方は[編集方針](/editorial-policy)を、キャリア相談の案内との関係は[広告・提携表記](/disclosure)をご覧ください。
