# 給料と土日休み、どう比べる？

2026年10月12日 更新 約6分で読めます

提案用のサンプル原稿です（人による最終確認・公開承認の前）。[詳しく](/editorial-policy)

[出典3件・記事の確認状況](#editorial-sources)

この記事の要点

給料と休みは、同じ項目をそろえて比べよう。

- 月給だけでなく、基本給・固定残業代・賞与を分けて見る。
- 「土日休み」の表記と、年間休日・休日出勤を確認する。
- 残業や通勤も含め、自分が続けられる働き方かを考える。

求人を比べていると、「年収は高いけれど休みが少ない」「土日休みだけど年収は少し低い」という選択に迷うことがあります。

どちらが正解というものはありませんが、比べ方を少し工夫すると、自分に合うほうが見えやすくなります。ポイントは、**数字の条件をそろえてから比べる**ことです。

## 年収が同じでも、毎月の給料は違う——比較の記入例

**次は架空の給与・休日条件を使った仮の例です。実際の求人、手取り額、賞与の支給を保証するものではありません。** どちらも12か月勤務した額面で計算し、固定残業代・交通費・その他手当は含まない設定です。

| 項目 | 仮の求人A | 仮の求人B |
| --- | --- | --- |
| 毎月の固定給与 | 25万円 | 23万円 |
| 賞与の仮定 | なし | 年24万円を満額支給すると仮定 |
| 年間の額面合計 | 25万円 × 12か月 = 300万円 | 23万円 × 12か月 + 24万円 = 300万円 |
| 年間休日 | 110日 | 120日 |
| 土日出勤 | 月1回ある設定 | ない設定 |

年間の合計は同じでも、毎月の固定給与はBが2万円少なくなります。また、Bの初年度賞与が支給されない場合、この例の年間額面は**276万円**です。賞与の実績を、そのまま自分の初年度の収入として足していないか確かめましょう。

「年収を下げたくない」が、毎月の生活費を守りたい意味なのか、年間の総額を守りたい意味なのかでも判断が変わります。土日休みについても、年間休日だけで判断せず、出勤の有無と振替の扱いを質問します。

求人を比較するときは、**固定給与・初年度の賞与条件・固定残業代の内訳・休日の曜日・試用期間の条件**を同じ表に入れ、不明なものは確認中とします。固定残業代の読み方は[固定残業代を含む求人の確認項目](/articles/koteizangyo-kyujin)へ。

毎月の生活費から考えるなら[手取りと額面の比較](/articles/tedori-20man-hikaku)、優先順位をつけるなら[条件整理チェック](/check)へ。[給料と休みを相談する](/consultation#support-conditions)ときは、合計額だけでなく、この内訳を手元に置けます。

## まずは「年間休日」で休みを数える

「土日休み」と書かれていても、祝日や夏季・年末年始の休みがあるかどうかで、1年間の休みの日数は変わります。求人票では、**年間休日の日数**を確認しましょう。

1年を52週で概算すると、毎週2日休みなら104日です。ただし、実際の年間休日はその年のカレンダーや会社の勤務予定によって変わります。下の104日・120日は日数の違いを考えるための例で、平均値や土日休みの保証ではありません。祝日が休みかも別に確認します。

> **図解: 年間休日の目安**
>
> - 毎週土日が休み
>   104日
>   1年はおよそ52週
> - 年間休日が120日の仮の例
>   120日前後
>   休みの曜日や内訳は別に確認

休日の書き方にも注意が必要です。**完全週休2日制**は毎週2日の休みがあることを指しますが、**週休2日制**は月に1回以上、週2日休める週があるという意味で、毎週とは限りません。

> **図解: 似ているけれど意味が違う**
>
> 完全週休2日制
>
> - 毎週2日の休みがある
>
> 週休2日制
>
> - 月に1回以上、週2日休める週がある
> - 毎週とは限らない

なお、労働基準法では、会社は少なくとも毎週1日（または4週間で4日以上）の休日を与えることになっていて、労働時間は原則として1日8時間・1週40時間までと定められています。年間休日が少ない求人は、1日の所定労働時間が短く設定されていることもあるので、あわせて確認しましょう。

## 年収は「内訳」まで見る

年収の欄には、いくつかの要素が合算されていることがあります。

| 年収に含まれやすいもの | 確認したいこと |
| --- | --- |
| 基本給 | 月給のうち、基本給はいくらか |
| 固定残業代 | 何時間分の残業代が含まれているか、超えた分は追加で支払われるか |
| 各種手当 | 住宅手当・資格手当など、誰でも受け取れるものか |
| 賞与（ボーナス） | 「前年実績」なのか、支給が決まっているのか |

特に**固定残業代**は、年収を比べるときに見落としやすいポイントです。たとえば同じ月給25万円でも、そのうち5万円が固定残業代なら、基本給は20万円になります。賞与が基本給をもとに計算される会社では、この差が年収にも影響します。

## 時給に換算してそろえて比べる

休日と年収のどちらを優先するか迷ったら、**1時間あたりの金額**に換算すると比べやすくなります。

計算はシンプルです。

> **図解: 1時間あたりの金額の出し方**
>
> 年収 ÷ 年間の勤務日数 × 1日の所定労働時間 = 1時間あたりの金額

次は、前の月給の例とは別の**架空の求人条件**です。1年365日・1日8時間・残業なしと仮定し、年収を年間の所定労働時間で割って比べます。有給休暇の取得日数や通勤時間は計算に含めていません。

|  | 求人A | 求人B |
| --- | --- | --- |
| 年収 | 300万円 | 320万円 |
| 年間休日 | 120日 | 105日 |
| 年間の勤務日数 | 245日 | 260日 |
| 1日の所定労働時間 | 8時間 | 8時間 |
| 年間の労働時間 | 1,960時間 | 2,080時間 |
| 1時間あたり | 約1,531円 | 約1,538円 |

年収では20万円の差がありますが、1時間あたりに直すとほとんど同じです。この場合、「休みが15日多いこと」と「年収が20万円高いこと」のどちらを取るかは、生活の中で何を大事にしたいかで決めることになります。

この表は給与と休日を比較するための概算で、**最低賃金を満たしているかの判定には使えません。** 最低賃金の計算では、賞与や時間外割増賃金など、対象から除く賃金があります（[厚生労働省・最低賃金の対象となる賃金（外部サイト）](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/chingin/newpage_43898.html)）。確認方法は[最低賃金の解説](/news/news-saitei-chingin-2026)を参照してください。

残業も含めて生活とのバランスを考える場合は、給与の比較範囲と労働時間の範囲をそろえます。残業代が年収に含まれるか不明なまま、時間だけを増やして比較しないようにしましょう。

## 給料も土日休みも大事なら、相談前に分ける3つの条件

すぐにどちらかを諦める必要はありません。次の欄を分けて、何が確認できれば応募を検討できるかを伝えます。

- **毎月守りたい収入**：賞与を含めず、生活に必要な額を考える。額面と手取りを区別する
- **休みの曜日と例外**：毎週の土日が必要か、月に何回までなら土日出勤を検討できるか
- **求人でまだ分からないこと**：初年度賞与、試用期間の給与、固定残業代、実際の残業など

数字が分からない欄は「未確認」のままで構いません。[条件整理チェック](/check)で優先順位をまとめるか、[給与と休日の比較を相談する](/consultation#support-conditions)内容を確認できます。

## 数字だけでは分からないこと

時給換算は便利ですが、数字だけでは比べられないこともあります。

- **休みの曜日**: 家族や友人と休みが合うか、平日休みのほうが都合がいいか
- **休みの取りやすさ**: 有給休暇を取りやすい雰囲気か、繁忙期はいつか
- **これからの伸び**: 昇給のしくみや、経験を積んだあとの年収の幅

こうした点は求人票に書かれていないことも多いので、面接や、人材紹介会社のキャリアアドバイザーとの面談で確認しましょう。面談前の準備は[エージェント面談前に決めておくこと・決めなくていいこと](/articles/agent-mendan-mae)で紹介しています。

「休み」と「年収」のどちらを優先するかに正解はありません。数字の条件をそろえて比べたうえで、自分の生活に合うほうを選ぶことが、入社後の「こんなはずじゃなかった」を減らす近道です。

## よくある質問

**Q: 「週休2日制」と「完全週休2日制」は何が違いますか？**

一般的に、完全週休2日制は毎週2日の休みがあることを指します。週休2日制は、月に1回以上は週2日の休みがある週があるという意味で使われ、毎週2日休めるとは限りません。休日の欄は、年間休日数とあわせて確認しましょう。

**Q: 固定残業代が含まれている求人は避けたほうがいいですか？**

固定残業代そのものが問題というわけではありません。基本給と固定残業代がそれぞれいくらか、何時間分の残業が含まれているか、それを超えた分が追加で支払われるかを確認し、ほかの求人とそろえて比べることが大切です。
