# 接客経験を、転職で活かすには？

2026年10月12日 更新 約5分で読めます

提案用のサンプル原稿です（人による最終確認・公開承認の前）。[詳しく](/editorial-policy)

[出典4件・記事の確認状況](#editorial-sources)

この記事の要点

接客で担当した仕事や工夫を、具体的に伝えましょう。

- 注文や要望を聞く → 相手の話を整理する経験。
- 混雑時の対応 → 優先順位を決めて動いた経験。
- 新人への説明 → 手順を分かりやすく伝えた経験。

「接客しかしてこなかったから、アピールできることがない」。転職を考え始めたとき、そう感じて手が止まっていませんか。

けれど、接客の仕事を細かく分けてみると、ほかの職種でも求められる経験がたくさん含まれています。大事なのは「接客をしていました」とまとめずに、**中身を分解して言葉にする**ことです。

## 求人票に合わせて、接客経験を3行で整理する

「経験がある」だけでは、応募する仕事との接点が伝わりません。気になる求人を1つ開き、**求人の作業 → 自分がしたこと → まだ未経験のこと**を分けてメモします。

次は編集部が作成した**架空の記入例**です。採用実績や、適職を判定した結果ではありません。

| 求人に書かれた作業 | 自分が実際に担当したことの例 | 応募前に確かめること |
| --- | --- | --- |
| 電話の取り次ぎ | 店舗の予約電話で日時・人数を確認した | 社内の取り次ぎ手順を入社後に学べるか |
| データ入力・確認 | レジ締めで金額を照合した | 使用するソフトと、入社時に必要な操作は何か |
| 社内への連絡 | シフト変更を確認し、担当者に伝えた | メールやチャットをどの程度使うか |

経験の整理には[マイジョブ・カードの求職者向け案内（外部サイト）](https://www.job-card.mhlw.go.jp/guidance/jobseeker)も参考になります。上の表は本メディア独自の整理例です。接客で経験したことと、事務でできる操作は分けて伝えましょう。経験が似ていても、応募条件を満たすとは限りません。

働き方の違いまで比べるなら[接客からオフィスへの変化](/articles/sekkyaku-office)、書類の形にするなら[アルバイト経験の職務経歴書](/articles/shokumu-keirekisho-arubaito)へ。まだ仕事を絞れない場合は[条件整理チェック](/check)でメモを作り、[経験の伝え方を相談する](/consultation#support-experience)ときの材料にできます。

## 接客の仕事を分解すると見えてくる経験

まずは、接客の仕事でふだんやっていることを書き出してみましょう。たとえば飲食店や販売店なら、次のような作業が含まれていることが多いはずです。

| 接客での場面 | その中に含まれている経験 |
| --- | --- |
| 注文や要望を聞く | 相手の話を聞き取り、必要な情報を確認する |
| 混雑時の対応 | 優先順位をつけて、複数の作業を同時に進める |
| クレーム対応 | 相手の気持ちを受け止めつつ、できることとできないことを伝える |
| 新人への説明 | 手順を分かりやすく言葉にして教える |
| 売上や客単価の目標 | 数字を意識して、おすすめのしかたを工夫する |
| レジ締め・在庫確認 | 数字を正確に扱い、ミスを防ぐ |

すべてに当てはまる必要はありません。自分が実際にやっていたものに印をつけ、その中で「工夫したこと」や「任されていたこと」を思い出してみてください。

## 職種ごとのつながり方

分解した経験は、職種によって活きる場面が変わります。代表的な職種とのつながりを見てみましょう。

### 営業

営業では、お客さまの困りごとを聞き取り、それに合う提案をします。接客で「お客さまの好みを聞いておすすめを選んでいた」経験は、そのまま提案の土台になります。売上目標を意識していた経験があれば、数字への向き合い方として伝えられます。

### カスタマーサポート

電話やメール、チャットで問い合わせに対応する仕事です。接客でのクレーム対応や、よくある質問への説明は、もっとも近い経験の一つです。対面と違って表情が見えないため、言葉だけで状況を確認する丁寧さが求められます。

### 事務

事務と聞くとパソコン作業のイメージが強いですが、来客対応や電話対応、社内からの依頼の受付など、人とのやりとりも多い仕事です。レジ締めや在庫確認で数字を正確に扱っていた経験は、データ入力や書類チェックにつながります。

### ITサポート

社内外の「パソコンが動かない」「設定が分からない」といった困りごとに対応する仕事です。入社時に必要なIT知識と、入社後に教わる範囲は求人ごとに確認します。相手が何に困っているかを聞き取った経験は、対応のしかたを説明する材料になりますが、必要な技術や資格を代わりに満たすものではありません。

それぞれの仕事内容の違いは、[営業・カスタマーサポート・ITサポートの違い](/articles/eigyo-cs-it-support-chigai)や[職種比較ページ](/jobs)で詳しく比べられます。

## 職務経歴書での書き方の例

経験を分解できたら、書類で伝えるときは「状況 → 自分がしたこと → 結果」の順に書くと伝わりやすくなります。

> **図解: 職務経歴書はこの順で書く**
>
> 1. 状況
>    例：席数40席の飲食店でホールを担当
> 2. 自分がしたこと
>    例：待ち時間の案内を声がけで行うよう提案
> 3. 結果
>    例：お待たせに関するご意見が減った

**以下は架空の経歴を使った例です。担当業務・数字・結果は、自分が説明できる事実に置き換えてください。**

**仕事内容だけを書いた例**

> 飲食店でホールスタッフとして接客を担当。コミュニケーション力を活かしてお客さまに対応しました。

**工夫した対応まで書いた例**

> 席数40席の飲食店で、ホールスタッフとして注文受付・会計・新人教育を担当（約2年）。混雑する週末に待ち時間の案内を声がけで行うよう店長に提案し、お待たせに関するご意見が減った。新人向けにレジ操作の手順を1枚にまとめ、教える側の負担も軽くなった。

数字は正確なものだけを書きましょう。覚えていない数字を盛る必要はありません。「約」「〜くらい」で正直に書くほうが、面接で深掘りされたときにも答えやすくなります。

## 伝えるときに気をつけたいこと

接客経験を伝えるときは、次の2点を意識すると印象が変わります。

- **「好き」だけで終わらせない**: 「人と話すのが好き」に加えて、どんな場面でどう対応していたかを添える
- **応募する仕事との接点を一言入れる**: 「問い合わせ対応の経験を、カスタマーサポートでの電話対応に活かしたい」のように、つながりを自分の言葉で示す

志望動機での伝え方は、[未経験職種の志望動機、何を書けばいい？](/articles/shiboudouki-mikeiken)で例文つきで紹介しています。

まずは、応募先の作業に近い経験を1つ選び、「担当したこと」「工夫したこと」「まだ学ぶ必要があること」を書き出してみましょう。伝え方を見てもらいたい場合は、[経験を活かすための相談内容](/consultation#support-experience)を確認できます。

## よくある質問

**Q: アルバイトの接客経験でも、職務経歴書に書いていいのでしょうか？**

書いて構いません。雇用形態よりも、どんな業務をどのくらいの期間担当し、何を工夫したかが判断材料になります。正社員経験と区別がつくよう、雇用形態と期間は正確に書きましょう。

**Q: 「コミュニケーション力があります」とだけ書くのはダメですか？**

ダメではありませんが、読み手に伝わりにくくなります。「1日に何人くらいのお客さまに対応していたか」「どんな問い合わせが多かったか」など、場面が浮かぶ事実を添えると説得力が増します。
