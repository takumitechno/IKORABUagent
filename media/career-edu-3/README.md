# 転職の教育ショート 第三弾（5本）

未経験で転職を考える20代〜30代前半（給料の低さ・働き方に不満がある人）に向けた、「やりがちな思い込み」を正す教育ショートです。1080×1920、30fps、H.264＋AAC。
ナレーションはユーザー支給の音声（落ち着いた男性の声）を、録音したままの速度で使っています。図解・比較・字幕は編集で作っています。
背景は画面いっぱいの写真（人物・手元・場所）で、シーンごとに（長いシーンは途中でも）切り替え、ゆっくりズームさせています。写真は新しく作った4枚と既存のAI画像の使い回しです（`../IMAGES.md`）。

## フォルダ

| 場所 | 中身 |
|---|---|
| `narration/<名前>_jin.mp3` | 支給ナレーション |
| `narration/scripts.json` | 全文字幕の区切り（話している文をそのまま。間の位置で区切っている） |
| `narration/<名前>_words.json` | 音声認識の単語時刻（図を出すきっかけの位置合わせ用。認識ミスを含む） |
| `timing/<名前>.json` | 編集用データ：シーン・全文字幕・強調テロップ・きっかけの時刻。`timing/<名前>.md` は同じ内容の表 |
| `img/e3_*.jpg` | このシリーズで新しく作った背景写真（無圧縮の元データは `img/png/`） |
| `src/edu3.py` | このシリーズの設定（構成 PLANS、追加の部品、音、コマンド）。第二弾の `edu.py` を読み込んで使う |
| `src/v01_holidays.py`〜`v05_agent.py` | 各動画の画面構成 |

## 書き出し

```
cd media/career-edu-3/src
python3 edu3.py fit career_edu_3_01_holidays       # 音声から時刻表を作る（手で直した時刻表は上書きされる）
python3 edu3.py preview v01_holidays 0.5 3.5 6.5   # 指定した秒のコマを out/preview/ に一覧で出す
python3 v01_holidays.py                           # 書き出し → out/career_edu_3_01_holidays.mp4
python3 edu3.py check career_edu_3_01_holidays     # 検査
```

フォントは初回だけ `../recruit-shorts/sales-to-jimu/fetch_fonts.sh` で取得します。

## 作り方の決めごと

- 冒頭：最初のコマから警告バッジ（黄色の三角＋「転職の落とし穴」など）と、その動画の疑問の見出しを出す。注意音はナレーションと同じくらいの大きさ
- 画面の構成：背景に写真（軽くぼかして暗くする）、上部に見出し、中央に図解（カレンダー、分岐図、NG例と改善例、残高の棒グラフ、チャット）、下に全文字幕
- 見出しがナレーションと同じ内容のときは、見出しが出ている間その字幕を出さない（同じ文が2か所に出ないように）
- 数字は台本にあるものだけ（60万円、月20万円、3か月）。住民税・保険料は金額を出さず、斜線で「この分減る」とだけ示し、「※支払いの額は人によって違います」と添える
- カレンダー・求人・チャットは「説明用の例」と表示する
- 誘導（相談・LINE・プロフィール・フォロー）、ロゴ、会社紹介は入れない。最後は締めの一言で自然に終える
- BGM：エレピとパッドの短調の静かな曲（Am–F–Dm–E）に、小さなハイハットの刻み。ナレーション中は音量を下げる
- 効果音：カードや項目が出るときに小さく、場面転換に軽い「シュッ」

## 未確認のこと

- 音はこちらで聴けないため、聞こえ方・字幕との合い方・BGM の音量感は数値でしか確認していません
- 音声認識で台本と違って聞き取られた箇所（認識の誤りの可能性が高いが、耳で確認が必要）
  - ③「給与条件」→「給料条件」（字幕は台本どおり「給与条件」）
- ①の冒頭「転職の落とし穴。」、②の冒頭「接客から転職＝事務一択？」は音声にあり台本の本文にはない一言で、①は警告バッジ、②は見出しとして画面に出しています
