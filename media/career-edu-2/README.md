# 転職の教育ショート 第二弾（5本）

はじめての転職・未経験転職で迷う20代に向けた、求人の見方と自己PRの書き方の教育ショートです。1080×1920、30fps、H.264＋AAC。
ナレーションはユーザー支給の音声（Fish Audio、声：Jin）を、録音したままの速度で使っています。図解・比較表・字幕は編集で作っています。
背景は画面いっぱいの写真（人物・手元・店や職場の背景だけ）で、シーンごとに（長いシーンは途中でも）切り替え、ゆっくりズームさせています。写真は既存のAI画像の使い回しです（`../IMAGES.md`）。

| 番号 | ファイル | 長さ | テーマ |
|---|---|---|---|
| ① | `out/career_edu_2_01_salary.mp4` | 23.7秒 | 転職先の月給、内訳を見よう |
| ② | `out/career_edu_2_02_annual_income.mp4` | 21.5秒 | 求人の年収例と、入社時の条件 |
| ③ | `out/career_edu_2_03_training.mp4` | 21.0秒 | 未経験転職で聞く、研修の中身 |
| ④ | `out/career_edu_2_04_office_work.mp4` | 20.6秒 | 接客から事務へ、仕事内容を比較 |
| ⑤ | `out/career_edu_2_05_self_pr.mp4` | 20.7秒 | 転職の自己PR、接客経験の書き方 |

MP4 はリポジトリに入れていません（`out/` は `.gitignore`）。下の手順で書き出し直せます。

## フォルダ

| 場所 | 中身 |
|---|---|
| `narration/<名前>_jin.mp3` | 支給ナレーション |
| `narration/scripts.json` | 全文字幕の区切り（台本の文をそのまま使用） |
| `narration/<名前>_words.json` | 音声認識の単語時刻（図を出すきっかけの位置合わせ用。認識ミスを含む） |
| `timing/<名前>.json` | 編集用データ：シーン・全文字幕・強調テロップ・きっかけの時刻。`timing/<名前>.md` は同じ内容の表 |
| `src/edu.py` | このシリーズの設定（構成 PLANS、図解の部品、コマンド） |
| `src/e01_salary.py`〜`e05_self_pr.py` | 各動画の画面構成 |

字幕・テロップ・最終的な書き出しは `../makecareer/src/` の共通の道具（`mc.py` など）を使っています。

## 書き出し

```
cd media/career-edu-2/src
python3 edu.py fit career_edu_2_01_salary          # 音声から時刻表を作る（手で直した時刻表は上書きされる）
python3 edu.py preview e01_salary 0.5 3.5 6.5       # 指定した秒のコマを out/preview/ に一覧で出す
python3 e01_salary.py                              # 書き出し → out/career_edu_2_01_salary.mp4
python3 edu.py check career_edu_2_01_salary         # 検査
```

フォントは初回だけ `../recruit-shorts/sales-to-jimu/fetch_fonts.sh` で取得します。

## 作り方の決めごと

- 冒頭の画面は、最初のコマから「転職の話の見出し」と「その動画の疑問」を出す
- 画面の構成：背景に写真（軽くぼかして暗くする）、上部に見出し、中央に図解、下に全文字幕。最上部に「※画像はAI生成によるイメージです」（第一弾と同じ配置）
- 全文字幕は画面下、強調テロップ（見出し）は画面上部。冒頭の見出しが字幕の文をそのまま含むとき（①）は、見出しが出ている間その字幕を出さない
- 金額は「説明用の例」と表示する。積み上げ棒は 20:5 の比率どおり。台本にない金額・時間数・手取り額は出さない
- 誘導（無料相談・LINE・プロフィール・フォロー）、ロゴ、会社紹介は入れない
- BGM はエレピとパッドの静かな曲（ドラムなし）で、ナレーション中は音量を下げる
- 効果音：最初のコマに注意音（ナレーションと同じくらいの大きさ）。カードや項目が出るときの音は第一弾と同じくらい。場面転換に軽い「シュッ」
- 最後の言葉のあとは1.5秒で終える（長いエンドカードは入れない）

## 未確認のこと

- 音はこちらで聴けないため、聞こえ方・字幕との合い方・BGM の音量感は数値でしか確認していません
- 音声認識で台本と違って聞き取られた箇所（認識の誤りの可能性が高いが、耳で確認が必要）
  - ②「賞与」（2か所）→「昭和」
  - ④「電話対応の多さ」→「大勢」、「人とのやり取り」→「人とも」
