## 制作方法

- **場面画像**：Figma プラグインの AI 画像生成（`generate_image` / gemini-3.1-flash-image）で、日本のオフィスや通勤電車の実写風カットを10枚生成（`img/`）。
- **動画**：`src/` の Python（PIL + ffmpeg）で合成。手持ちカメラ風のゆっくりしたズーム、色調補正、フィルムグレイン、テロップのポップアニメーションを付けています。
- **リアルさを出すUI演出**：上司からのチャット通知、ノルマ達成率カード、今日の予定表、Excel風の請求データ入力、チームチャットの「ありがとう」、スキル対応表。どれも特定の実在サービスに似せない汎用デザインです。
- **音**：BGM（前半は哀しいピアノ→後半は前向き／lo-fiビート）と効果音（通知音、話し中音、セミ、タイピング音など）をコードで生成しているので、著作権のある素材は使っていません。

### 再生成

```sh
bash fetch_fonts.sh                # Noto Sans JP（OFL）を fonts/ に取得
pip install pillow numpy scipy
cd src && python3 video_a.py && python3 video_b.py   # out/ に mp4 を出力
python3 preview.py video_b sheet.jpg 1.5 12 20       # 指定秒数のフレームを一覧画像に
```
