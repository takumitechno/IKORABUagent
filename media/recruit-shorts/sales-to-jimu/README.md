# 未経験転職ショート動画：営業 → 事務職（2本）

営業が合わなかった人に向けて、事務職への未経験転職を呼びかける縦型ショート動画です（TikTok / Instagram リール / YouTube ショート向け）。

## 制作方法

- **場面画像**：Figma プラグインの AI 画像生成（`generate_image` / gemini-3.1-flash-image）で、日本のオフィスや通勤電車の実写風カットを10枚生成（`img/`）。
- **動画**：`src/` の Python（PIL + ffmpeg）で合成。手持ちカメラ風のゆっくりしたズーム、色調補正、フィルムグレイン、テロップのポップアニメーションを付けています。
- **リアルさを出すUI演出**：上司からのチャット通知、ノルマ達成率カード、今日の予定表、Excel風の請求データ入力、チームチャットの「ありがとう」、スキル対応表。どれも特定の実在サービスに似せない汎用デザインです。
- **音**：BGM（前半は哀しいピアノ→後半は前向き／lo-fiビート）と効果音（通知音、話し中音、セミ、タイピング音など）をコードで生成しているので、著作権のある素材は使っていません。

### Fish Audio のサイトで作った音声を使う（今回の方法）

Fish Audio の API 残高がなくても、サイトの「Text To Speech」（プランのクレジット）で作った音声をそのまま使えます。
声は「Jin」で、動画ごとに台本を1回で読み上げた mp3 を `narration/` に置いています。

```sh
cd src
python3 align_clips.py ../narration/video_c_fish.mp3 ../narration/video_c_lines.json ../clips/c   # 無音の位置からセリフごとに切り分け
python3 align_clips.py ../narration/video_d_fish.mp3 ../narration/video_d_lines.json ../clips/d
TTS_BACKEND=clips python3 video_c.py   # out/video_c_hook_check_clips.mp4
TTS_BACKEND=clips python3 video_d.py   # out/video_d_hook_nige_clips.mp4
```

- 切り分けは、セリフ間の無音とセリフの文字数の比率を照らし合わせて行います（`align_clips.py`）。
- 音程を変えずに 1.2 倍速にしています（`TTS_SPEED_MUL` で変更可）。
- 字幕のポップやズームの切り替えは、セリフ内の実際の息継ぎ位置に合わせています。

### Fish Audio の API で仕上げる手順

1. 環境設定（セッション上部の環境メニュー →「Edit」）
   - 「Allowed domains」に `api.fish.audio` を追加
   - Fish Audio の API キーを環境変数 `FISH_API_KEY` として登録（Network secrets か環境変数）
2. 新しいセッションを開き、次を実行

```sh
cd media/recruit-shorts/sales-to-jimu
bash fetch_fonts.sh && pip install pillow numpy scipy
cd src
python3 fish_voices.py 男性 ナレーション      # 日本語の声の一覧から FISH_VOICE_ID を選ぶ
TTS_BACKEND=fish FISH_VOICE_ID=<ID> python3 video_c.py   # out/video_c_hook_check_fish.mp4
TTS_BACKEND=fish FISH_VOICE_ID=<ID> python3 video_d.py   # out/video_d_hook_nige_fish.mp4
```

- Fish Audio からは mp3 を受け取り、ffmpeg で音程を変えずに 1.2 倍速にしています（`TTS_SPEED_MUL` で調整可）。
- `FISH_MODEL` を指定しない場合は `s2-pro`、だめなら `s1` の順に試します。
- 商用利用できるかは、Fish Audio のプランと、選んだ声のモデルの利用規約で決まります。投稿前に確認してください。

### ナレーションの声を切り替える

`TTS_BACKEND` で読み上げエンジンを選びます（`src/tts.py`）。

| `TTS_BACKEND` | 必要なもの | 声 |
|---|---|---|
| `fish` | 環境変数 `FISH_API_KEY`、`FISH_VOICE_ID`（使う声のモデルID）、通信先 `api.fish.audio` の許可 | Fish Audio の任意の声（本番向け） |
| `voicevox` | `VOICEVOX_DIR`（onnxruntime・辞書・VVMモデルを置いたフォルダ）、`pip install voicevox_core`、通信先 GitHub の許可 | 既定は 青山龍星（`VOICEVOX_STYLE_ID=13`）。CTAに「VOICEVOX:青山龍星」のクレジットを自動表示 |
| `kokoro` | `bash fetch_kokoro.sh`（npm の expo-kokoro からモデルを取得し、日本語の読み変換を導入） | Kokoro-82M のニューラル音声。既定は日本語男性 `jm_kumo`（`KOKORO_VOICE=jf_alpha` で女性）。Apache-2.0 でクレジット表記は不要 |
| `openjtalk`（既定） | `pip install pyopenjtalk-plus` | 内蔵の女性声（仮音声・尺確認用） |

Kokoro は数字の読みを誤ることがあるため、ナレーション用の文では「みっつ」「いちにち」のようにひらがなで書いています（テロップの表記はそのまま）。

```sh
bash fetch_kokoro.sh
cd src
TTS_BACKEND=kokoro python3 video_c.py   # out/video_c_hook_check_kokoro.mp4
TTS_BACKEND=kokoro python3 video_d.py   # out/video_d_hook_nige_kokoro.mp4
```
