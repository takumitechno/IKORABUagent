# MakeCareer 縦型ショート 5本

MakeCareer の無料相談へつなぐ縦型ショート（1080×1920、30fps、H.264＋AAC）。ナレーションはユーザー支給の Fish Audio 音声（声：Jin）を録音したままの速度で使い、BGM と効果音をこちらで足しています。
書き出しには営業→事務の動画と同じエンジン（`../recruit-shorts/sales-to-jimu/src/engine.py` ほか）を使っています。

| 番号 | ファイル | 長さ | 主人公 |
|---|---|---|---|
| ① | `out/01_yaritai_shigoto.mp4` | 29.4秒 | 接客（パン屋）から転職したい男性 |
| ② | `out/02_jibun_no_tsuyomi.mp4` | 27.6秒 | 雑貨店の販売経験がある女性 |
| ③ | `out/03_seishain.mp4` | 30.9秒 | カフェでアルバイトをしている女性 |
| ④ | `out/04_korekara_no_hatarakikata.mp4` | 26.8秒 | 入社3年目の男性 |
| ⑤ | `out/05_skill_fuan.mp4` | 27.4秒 | 資格の勉強から始めようとしている男性 |

MP4 はリポジトリに入れていません（`out/` は `.gitignore`）。下の手順でいつでも書き出し直せます。

## フォルダ

| 場所 | 中身 |
|---|---|
| `narration/*_jin.mp3` | 支給ナレーション（元のファイル名の先頭が動画タイトルなので、それで各動画に割り当てた） |
| `narration/scripts.json` | 動画ごとの全文字幕の区切り（確定候補ナレーションを段落ごとに読みやすく分けたもの） |
| `narration/*_words.json` | 音声認識（faster-whisper small）の単語時刻。行の中の位置合わせにだけ使う。認識ミスを含む |
| `timing/*.json` | **編集用データ**：シーン・全文字幕・強調テロップ・演出のきっかけ（marks）の時刻 |
| `timing/*.md` | 同じ内容のタイミング表（書き出し時に自動生成） |
| `src/mc.py` | 5本共通の部品（字幕、強調テロップ、写真の窓、図解、最終画面、BGM・効果音） |
| `src/v0N_*.py` | 各動画の構成 |
| `src/fit_audio.py` | ナレーションに合わせて `timing/*.json` を作り直す |
| `img/` | 画像（一覧は `../IMAGES.md`） |

## 書き出し

```
cd media/makecareer/src
../../recruit-shorts/sales-to-jimu/fetch_fonts.sh     # 初回のみ（フォント）
python3 v03_seishain.py                               # → out/03_seishain.mp4 と .srt、timing/03_seishain.md
```

- 字幕や切り替えの時刻を直すときは `timing/<動画>.json` を書き換えて、上のコマンドを実行し直します。
- 音声を差し替えたときは、`narration/<動画>_jin.mp3` を置き換えてから `python3 fit_audio.py <動画>` を実行します。手で直した `timing/*.json` は上書きされます。
- 音声なしの映像だけが必要なときは、各スクリプトの `mc.render(...)` に `with_audio=False` を渡します。

## 作り方の決めごと

- **ナレーション**：速度は変えていません。支給音声の冒頭にある動画タイトルの読み上げ（例：③「そろそろ正社員になりたい」）は確定ナレーションに含まれないので使わず、本文の第1段落から使っています。
- **全文字幕**：画面下の決まった位置（SNSの操作表示より上）。音声に合わせて、意味の区切りで切り替えます。冒頭の強調テロップがその字幕の文をそのまま含むとき（①②⑤の最初の1文）は、同じ文が上下に並ばないよう、テロップが出ている間は字幕を出しません。
- **強調テロップ**：画面上部に短く。字幕と同じ長文は出しません。
- **写真**：顔や手元が字幕とテロップに隠れないよう、写真は中央に窓として置き、その背景に同じ写真をぼかして敷いています。写真に写り込んだ文字やロゴはぼかしています。
- **BGM**：エレピとパッドの静かな曲。サービス紹介の段落から軽いリズムが入ります。ナレーション中は音量を下げています。
- **効果音**：カードやメモが出る、項目を書くといった画面上の動きにだけ小さく付けています。場面転換と最後の誘導画面には付けていません。
- **最終画面**：5本共通のレイアウト（サービス名・その動画の相談テーマ・無料相談／無料面談・プロフィールのリンクから）。ロゴ、URL、QRコードは使っていません。

## 未確認のこと

- 音はこちらで聴けないため、ナレーションと字幕の合い方、BGM・効果音の音量感は数値でしか確認していません（ナレーションの配置は予定位置とのずれ0秒、BGMはナレーションより約10dB小さい）。
- 音声認識では、③の「履歴書」が2か所とも「歴史」、「バイト」が「場合と」と聞き取られました。認識の誤りの可能性が高いですが、読み間違いでないか耳で確認してください。
- 「20代の未経験転職をサポート」など、サービスについての文言は支給ナレーションのままです。内容がサービスの実態と合っているかは確認していません。
