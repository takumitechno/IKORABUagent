# NEXT01〜NEXT05（未経験転職SNSメディア／TikTok・Reels）

合同会社 匠Technologies の未経験転職SNSメディア向けの縦型ショート5本。1080×1920、30fps、H.264＋AAC。
納品物・投稿用テキスト・公開前の確認事項は `DELIVERY.md` にあります。

作りは教育ショートの第三弾（`../career-edu-3/`）と同じ道具を使い、SNS向けにメリハリを強めています。

- 0秒目：テーマのラベル（例「未経験転職｜給料の比べ方」）と見出しを同時に出し、短く強いインパクト音
- 背景：画面いっぱいの写真（既存のAI画像の使い回し、`../IMAGES.md`）。カットごとに少し寄ってから落ち着き、ゆっくり寄る／引く
- 図解：比較カード、条件カード、2列の仕分け、カレンダー、チェックリスト。数字や条件の図だけに「例」「説明用の例」
- 字幕は画面下（全文、2行まで）、強調テロップは画面上。テロップが字幕と同じ内容のときは字幕を出さない
- 「画像はイメージです」などの注記は出さない
- CTA：NEXT01・04 は保存マーク、NEXT03・05 は「プロフィールのリンクへ」、NEXT02 はなし

## 音

- ナレーション：支給音声（Fish Audio、1.3倍速で生成済み）をそのままの速度で使う。頭の無音だけ詰めている
- 効果音（`src/nx.py` の `SE`）：冒頭のインパクト音、カードや数字のポップ音・クリック音、「実は違う」のアクセント音、NG のブザー音、場面転換のスワイプ音、CTA の決め音。ナレーションと重なる部分だけ 4dB 下げる
- BGM：軽いドラムとピアノ／エレピの曲を動画ごとに変えている（`STYLES`）。ナレーション中は 10dB 下げる
- 効果音・BGM はすべてプログラムで生成した音で、外部の音源は使っていない
- 書き出し時に −14 LUFS にそろえる

## フォルダ

| 場所 | 中身 |
|---|---|
| `narration/<名前>_jin.mp3` | 支給ナレーション |
| `narration/scripts.json` | 全文字幕の区切り（音声の書き起こしから作成。台本が届いたら照合する） |
| `narration/<名前>_words.json` | 音声認識の単語時刻（認識ミスを含む） |
| `timing/<名前>.json` | 編集用データ：シーン・全文字幕・強調テロップ・きっかけの時刻。`timing/<名前>.md` は同じ内容の表 |
| `src/nx.py` | このシリーズの設定（構成 PLANS、背景の動き、部品、効果音、BGM、書き出し、コマンド） |
| `src/n01_salary.py`〜`n05_holidays.py` | 各動画の画面構成 |

## 書き出し

```
cd media/next-shorts/src
python3 nx.py fit NEXT01_salary          # 音声から時刻表を作る（手で直した時刻表は上書きされる）
python3 nx.py preview n01_salary 0.5 3.0  # 指定した秒のコマを out/preview/ に一覧で出す
python3 n01_salary.py                    # 書き出し → out/NEXT01_salary.mp4 と .srt
python3 nx.py check NEXT01_salary        # 検査（解像度・長さ・音声の位置・音量・字幕の行数）
```

フォントは初回だけ `../recruit-shorts/sales-to-jimu/fetch_fonts.sh` で取得します。
